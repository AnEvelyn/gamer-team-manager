# Gamer Team Manager

O Gamer Team Manager é um mini sistema em linha de comando (CLI) desenvolvido para o gerenciamento de uma equipe de gamers.

> **Projeto Prático - Trilhas Inova Backend (Módulo I)**  
> Este é o primeiro projeto prático desenvolvido durante a formação de Backend do programa **Trilhas Inova**, com o objetivo de fixar conceitos como lógica de programação, manipulação de arrays, objetos e estruturas de controle em JavaScript.
> 

## Funcionalidades

- **Cadastrar Jogador:** Registro de nome, função no time e pontuação inicial.
- **Deletar Jogador:** Remoção de integrantes da equipe pelo nome.
- **Mostrar Equipe:** Listagem de todos os jogadores cadastrados com suas respectivas funções e pontos.
- **Atualizar Pontos:** Incremento da pontuação de um jogador específico.
- **Buscar Jogador:** Consulta individual dos dados de um integrante.
- **Cálculo da Média:** Exibição da média de pontuação total do time.
